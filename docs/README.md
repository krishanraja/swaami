## 🔧 Tech Stack Summary

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + shadcn/ui components
- **Backend**: Supabase (PostgreSQL, Auth, Storage, Edge Functions)
- **Database**: PostgreSQL with Row Level Security
- **AI**: Google AI / OpenAI (optional)
- **Payments**: Stripe
- **Deployment**: Vercel (frontend) + Supabase (backend)
- **State**: React Query + Context patterns
- **Routing**: React Router v6

## 🗂️ Key Files Reference

### Entry Points
- `src/main.tsx` - Application entry
- `src/App.tsx` - Routes and providers
- `index.html` - HTML template with splash

### Configuration
- `package.json` - Dependencies
- `vite.config.ts` - Vite configuration
- `tailwind.config.ts` - Tailwind configuration
- `vercel.json` - Vercel SPA routing
- `supabase/config.toml` - Supabase configuration

### Core Hooks
- `src/hooks/useAuth.ts` - Authentication
- `src/hooks/useProfile.ts` - User profile
- `src/hooks/useTasks.ts` - Task operations
- `src/hooks/useMatches.ts` - Match operations
- `src/hooks/useMessages.ts` - Chat messages
- `src/hooks/useTrustTier.ts` - Trust tier calculation
- `src/hooks/useNeighbourhoods.ts` - Neighbourhood selection

### Core Utilities
- `src/lib/logger.ts` - Structured logging
- `src/lib/validation.ts` - Zod schemas
- `src/lib/safety.ts` - Content moderation
- `src/lib/stateMachine.ts` - State validation
